# 🎓 Placement Portal

A complete College Placement Management System built with Java, JSP, Servlets, and MySQL.

## ✨ Features

### Admin Panel
- Dashboard with analytics charts
- Manage Students, Companies, Jobs (CRUD)
- Applications management with status update
- Auto-shortlisting based on eligibility
- Events management + Attendance tracking
- CSV export for students and shortlist

### Student Panel
- Personalized dashboard
- Browse and apply for jobs
- Track application status
- Mark event attendance
- Update profile and upload resume
- Real-time notifications

### Company Panel
- Separate company login
- Post new jobs
- View posted jobs

## 🛠️ Tech Stack

- Java 17
- JSP + Servlets
- MySQL 8.0
- Apache Tomcat 9.0
- Bootstrap 5, Chart.js, Font Awesome

## 🚀 Setup

1. Import project in Eclipse
2. Configure DB in `DBConnection.java`
3. Add project to Tomcat server
4. Start Tomcat
5. Open: `http://localhost:8080/PlacementWeb/login.jsp`
