# 🎓 Placement Portal

A Java-based College Placement Management System that helps manage students, companies, jobs, and shortlisting for campus placements.

---

## ✨ Features

- **Student Management** – Add and view students with CGPA, branch, and skills.
- **Company Management** – Add and view recruiting companies.
- **Job Management** – Post job openings with eligibility criteria (CGPA, branch, skills).
- **Shortlisting** – Automatically shortlist students who meet a job's criteria.
- **Applications** – Students can apply for jobs, and status can be tracked.
- **MySQL Database** – All data is persisted in MySQL.
- **Console Menu** – Simple, interactive command-line interface.

---

## 🛠️ Tech Stack

- **Language:** Java (JDK 17+)
- **Database:** MySQL 8.0
- **Connectivity:** JDBC (MySQL Connector/J)
- **IDE:** Eclipse
- **Version Control:** Git + GitHub
